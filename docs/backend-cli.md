# CLI аргументи запуску нашого Backend

## help
Показати всі можливі команди та аргументи


## serve
Запускає робочий бекенд сервер

* --dont-migrate - не запускати міграції автоматично
* --port=8080 - порт на якому запуститься сервер
* --no-openapi - не запускати ендпойнт з OpenAPI


## migrate
Операції з міграціями

* --schema=public - схема в якій знаходяться лог міграцій
* --create - не кидати помилку якщо таблиці з логами немає, а створити автоматично

### state
Показує на якій міграції зараз знаходиться БД

### log
Показує всю історію міграцій

### up
Застосовує всі міграції

### down
Відкат на одну міграцію


## openapi
Запускає сервер лише з Swagger та Healthcheck

* --port=8080 - порт на якому запуститься сервер
* --no-healthcheck - без ендпойнту Healthcheck
